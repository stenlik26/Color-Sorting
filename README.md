# Color Sorting Blocks (WIP)

A small puzzle game built with **Raylib** where the goal is to sort colored blocks into stacks of the same color.  

<!--![Screenshot](screenshot.png) -->

## Gameplay
- Each column contains a stack of blocks in different colors.  
- The objective is to move blocks around until each column has only one color.  
- Inspired by classic color sorting and water sort puzzle games.  

## Tech
- Written in **C/C++**  
- Uses [Raylib](https://www.raylib.com/) for rendering.
